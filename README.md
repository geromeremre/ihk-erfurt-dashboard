# IHK Erfurt – Interaktives CRM & BI Dashboard

**[🚀 Live-Dashboard öffnen](https://geromeremre.github.io/ihk-erfurt-dashboard/)**

Interaktives webbasiertes BI-Dashboard für Datenmanagement, CRM, Datenanalyse und Datenqualität mit KI-Potenzialen und IT-Bezug.

Eigenständiges Demoprojekt im Rahmen meiner Bewerbung bei der IHK Erfurt.

**Technologien:** HTML, CSS und JavaScript.

**Datenbasis:** Synthetische CRM-Daten sowie gesondert gekennzeichnete öffentliche Statistiken des Thüringer Landesamtes für Statistik.

**Hinweis:** Dieses Projekt ist keine offizielle Anwendung der IHK Erfurt und verwendet keine internen IHK-Daten.
