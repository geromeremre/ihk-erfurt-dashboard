# ihk-erfurt-dashboard
Interaktives BI-Dashboard für Datenmanagement, CRM, Datenanalyse und Datenqualität mit KI-Potenzialen und IT-Bezug. Eigenständiges Demoprojekt zur IHK-Stellenausschreibung; operative Beispieldaten sind synthetisch, amtliche Statistiken gesondert gekennzeichnet. Keine offizielle IHK-Anwendung.
